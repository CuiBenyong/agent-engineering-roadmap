# AI 入门学习路线与练习资源

从一个小任务开始：把要求讲清楚，让 AI 给出草稿，再拿原始资料核对。练习完成后，你会留下自己的提示词、检查记录和一份可以复用的工作成果。

这条路线面向刚开始使用 AI 的读者，无需编程。会写代码、想开发 Agent 的读者，可以回到[Agent 工程师学习路线](../README.md)。

配套课程来自[逐日AI](https://zhurilab.com/learn)。仓库内的练习、素材和模板可以独立使用；课程用于展开学习。仓库文档按[CC BY 4.0](../LICENSE)提供，链接到的网站课程不在该许可范围内。

## 先用十分钟做一次

1. 打开[练习 01：把需求说清楚](exercises/01-first-request.md)，复制其中的虚构素材。
2. 在你能正常使用的 AI 对话工具中，分别尝试模糊提问和明确提问。
3. 对照练习末尾的检查表，找出一个错误或可以改进的地方，追问一次。

不用先开通付费功能，也不需要 API key。若工具提示付费或功能不可用，可以改用已有的文字对话功能。工具的费用和可用范围以服务方实际说明为准。

## 14 次练习怎么安排

每次预留约 20–40 分钟，这是练习的建议时间，不包括完整课程阅读。可以一天做一次，也可以拆开完成；14 次练习不等于学完网站上的所有配套课程。

| 次数 | 今天练什么 | 留下什么 | 练习入口 |
|---|---|---|---|
| 01 | 写清任务、材料和限制 | 两版提示词及比较记录 | [第一次提问](exercises/01-first-request.md) |
| 02 | 分清已知、未知和推测 | 一张带来源的事实表 | [事实核查](exercises/02-check-facts.md) |
| 03 | 从讨论里提取行动项 | 负责人、期限和待确认项清单 | [会议纪要](exercises/03-meeting-notes.md) |
| 04 | 用已有证据写工作总结 | 一份没有虚构成绩的周报 | [周报](exercises/04-weekly-report.md) |
| 05 | 针对收件人组织文字 | 一封可人工审阅的邮件草稿 | [邮件](exercises/05-email.md) |
| 06 | 先找原文，再回答问题 | 带条款号的问答表 | [文档阅读](exercises/06-document-reading.md) |

| 11 | 用相同样例比较提示词 | 三个样例的 A/B 检查结果 | [小样本评估](evaluation.md) |

## 提示词之外，还要留下什么

每次保存四样东西：原始材料、实际使用的提示词、AI 的原始回答、你检查后的修订稿。不要只保存最满意的一次回答。失败的例子能帮助你发现哪些要求没有讲清楚。

- [可复制的提示词模板](prompts.md)
- [小样本评估与人工检查方法](evaluation.md)
- [学习记录和复盘模板](study-log.md)

使用真实材料时，先确认自己有权提供这些内容，并去除不需要的个人与工作信息。对外发送、提交申请或作出承诺前，由自己核对最终稿。

## 接下来学什么

想系统研究提示词，可以学习[5 天提示词工程零基础](https://zhurilab.com/learn/prompt-engineering-5days)。这门课包含代码任务、结构化输出和评估；完全不写代码的读者，可以先完成本仓库的文字练习，再按需阅读。

准备进入开发时，先具备一门编程语言、命令行和基本调试能力，再回到[工程路线](../README.md)。其中的[Claude 课程](https://zhurilab.com/learn/claude-mastery)、[Codex 课程](https://zhurilab.com/learn/codex-mastery)、[Agent 实战](https://zhurilab.com/learn/agent-30days)和[RAG 实战](https://zhurilab.com/learn/rag-14days)是后续方向，不需要在这 14 次入门练习中完成。

课程链接核对日期：2026-10-30。遇到失效链接或练习问题，欢迎在本仓库提交 Issue，附上文件名、问题位置和可复现的虚构样例。
