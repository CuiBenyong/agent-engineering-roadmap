# 练习 04 写一份有依据的周报

目标：把做过的事情写清楚，同时保留没有完成的部分。

## 虚构工作记录

```text
W1：本周收到 10 个资料整理请求，完成 7 个，另 3 个等待对方补充文件。
W2：整理了一份操作说明草稿，交给同事试读，尚未正式发布。
W3：参加两次需求讨论，留下会议记录；没有统计会议节省了多少时间。
W4：下周计划先跟进缺失文件，再根据试读反馈修改说明。
W5：没有上周的请求数，没有客户满意度数据，也没有工时数据。
```

## 动手做

请 AI 按“已完成、未完成及原因、下周安排”起草周报，每项注明 W 编号，正文控制在 250 个汉字以内。再让它检查哪些表达可能夸大成果。

## 检查标准

- [ ] 7 个已完成与 3 个待补材料没有混在一起。
- [ ] 操作说明仍是待试读反馈的草稿。
- [ ] 没有“效率提升 30%”“满意度显著提高”等无依据成绩。
- [ ] 若使用 70%，明确它指本周请求完成比例，即 7÷10。
- [ ] 下周安排来自 W4，没有冒出新的截止时间或承诺。

参考句：“本周完成 7 个资料整理请求，另 3 个待对方补充文件；操作说明已形成草稿，正在收集试读反馈。”不要把它扩写成“所有事项已顺利交付”。
