# 练习 08 按证据改简历，再练一次面试

目标：把经历讲清楚，识别岗位要求与已有能力之间的空缺。

## 虚构岗位与经历

```text
J1：岗位希望候选人能够整理客户反馈、维护表格、协调同事跟进问题。
J2：岗位提到 SQL 经验为加分项，没有说明这是必备条件。
J3：候选人小许在社团活动中整理过 36 条报名反馈，用表格分类并标注状态。
J4：小许曾与 2 名志愿者协调资料补交，保留了待办清单。
J5：小许没有客户公司的正式工作经历，没有学过 SQL。
J6：材料没有提供处理效率提升、收入增长或满意度数据。
```

## 动手做

先生成「岗位要求、已有证据、尚缺什么」对照表，再改写两条简历经历。最后请 AI 只问一个与这份经历有关的追问，等你用虚构材料作答后，再给反馈。

## 检查标准

- [ ] 36 条报名反馈没有被改成 36 家客户或 36 次商业项目。
- [ ] 社团经历没有包装成正式客户成功岗位经历。
- [ ] 协调 2 名志愿者没有扩大成管理团队。
- [ ] SQL 保留为能力空缺，没有写成“熟练掌握”。
- [ ] 没有编出业绩比例，面试反馈只评价你实际给出的回答。

参考要点：“整理并分类 36 条社团报名反馈，在表格中标注处理状态”；“与 2 名志愿者协同跟进资料补交，维护待办清单”。如果被问到尚未提供的成效数据，回答材料不足，并说明实际工作中需要记录什么。
